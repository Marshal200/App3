## App3

A minimal UIKit iOS application template with an `AppDelegate` and a single `ViewController`.

### Getting started

- Open `App3.xcodeproj` in Xcode on macOS.
- Select a simulator or device and run the app.

### Documentation

- Full API reference and examples: see `docs/API.md`.

### Project structure

- `App3/AppDelegate.swift`: Application lifecycle and bootstrap.
- `App3/ViewController.swift`: Sample screen demonstrating `UIViewController` basics.
- `App3/Info.plist`: App metadata and configuration.

### Extending

- Add new view controllers for additional screens.
- Configure the root UI and global appearance in `application(_:didFinishLaunchingWithOptions:)`.
